Methods / public operating notes

How payment findings are measured.

The methods library exists so a buyer can interrogate denominators, causal status, guardrails and annualization before accepting a recommendation.

How We Measure Authorization

Attempt-level denominator, terminal-state rules, exclusions, retries, capture distinction, cohort stability and basis-point reporting.

Why PSP Comparisons Are Usually Confounded

Traffic allocation, issuer mix, country, ticket size, method, risk, retry state, authentication and orchestration can create raw route gaps that are not causal.

How We Design Routing Experiments

Eligibility, randomization unit, assignment logging, sample-ratio checks, pre-specified outcome, confidence interval and fraud/cost guardrails.

How We Calculate Recovered Payment Value

Separate first-attempt failure, later recovery, customer action, retry cost and duplicate counting. Declined value is not automatically recoverable value.

How We Annualize Impact

Annualization uses eligible traffic and validated effect estimates, then subtracts incremental fraud, disputes, fees and operational losses. Projected value remains estimated.

How We Treat Fraud Guardrails

Authorization and fraud use compatible denominators. A conversion gain that raises net fraud/dispute loss can fail the decision rule.

How We Classify Declines

Raw provider code → normalized family → issuer/network context → retry eligibility → customer/merchant action → later recovery → value at stake.

How We Reconstruct Payment State

Trace order, payment, authorization, authentication, capture, refund, dispute, balance transaction, payout and internal ledger states.

How We Audit 3DS

Eligible → exemption/request → frictionless/challenge → completion → auth result → authorization → issuer result → final payment state.

How We Reconcile Payment Events

Exception-led matching across IDs, amounts, currencies, fees and timestamps with explicit unmatched, duplicated and state-disagreement classes.

How We Test Retry Strategy

Recovery by attempt number and time window, hard-decline suppression, customer-action routing, incremental processing cost and churn/fraud guardrails.

How We Report Uncertainty

Confidence intervals, sensitivity, missingness, data-quality warnings, identification status and falsification conditions accompany material conclusions.
