## What qualifies

- an independent rerun with a linked commit or issue;
- a payments professional reviewing a design assumption;
- a merchant/fintech team using an analysis query or test case;
- an external pull request adding a meaningful payment scenario;
- a public citation, import or fork used for a separate project.

Stars alone are not counted as validation.
