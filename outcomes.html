Outcome ladder

Value claims graduate one state at a time.

A large modeled number does not skip validation. Every result is labeled at the strongest completed state only.

01

LOSS OBSERVED

A measured failure or value concentration exists in production data. No recoverability is implied.

02

OPPORTUNITY ESTIMATED

A bounded model estimates what could be recoverable, with assumptions and uncertainty disclosed.

03

EXPERIMENT VALIDATED

A pre-specified intervention test supports an incremental effect with guardrails.

04

IMPLEMENTED

The merchant deployed the intervention beyond the test population.

05

FINANCIALLY REALIZED

Realized value is traceable to production accounting, settlement or equivalent validated evidence.

OUT-###

Outcome record

Baseline, treatment, N, window, effect, confidence interval, design, fraud/cost guardrails, implementation, annualization, evidence class and limitations.
