The production case is distinct from the synthetic 300,000-attempt reference environment and from Stripe provider-test execution. Nothing in those earlier evidence classes is retroactively relabelled as production evidence.

## What is public today

The public claim is limited to the retained evidence objects above. Checkout does **not** currently publish a client name, anonymized production metric, before/after chart, testimonial quote or intervention detail unless the corresponding disclosure permission has been cleared.

That means a buyer should read this page as **evidence that a measured production engagement exists**, not as a fully inspectable public case study.

## What a publishable production case must contain

A production case is promoted from aggregate proof to a public case only when permission covers enough detail to make it genuinely useful. The publication standard is:

| Required section | Minimum public content |
|---|---|
| Scope | merchant context at a level that does not identify the client unless named permission exists |
| Data perimeter | object types, date window, fields used, explicit excluded sensitive fields |
| Problem | the decision or failure surface the engagement was asked to resolve |
| Method | QA, denominator contract, diagnostic cuts, experiment/identification boundary |
| Finding | what the evidence supported and what remained unresolved |
| Action | what changed operationally, if anything |
| Outcome | 2–3 permissioned metrics with measurement windows and evidence class |
| Guardrails | fraud, dispute, latency, cost or lifecycle constraints where relevant |
| Limitations | what the case cannot establish |
| Permission | exactly what the client allowed to be disclosed |

A short anonymous story without measurement windows or evidence class does not qualify.

## Current publication gap

The highest-value next proof object is **one permissioned production case with 2–3 defensible metrics**, or a named external reviewer/client quote with explicit publication permission. Until that exists, the site should not pretend the aggregate counts answer every buyer diligence question.
