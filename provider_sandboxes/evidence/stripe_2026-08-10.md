# Stripe sandbox evidence — 2026-08-10

This record documents execution of the repository's Stripe PaymentIntent test path against Stripe's test environment using a developer-owned test secret key. No API keys, client secrets, customer data, full account identifiers, or raw certificate material are retained here.

## Execution status

The four repository scenarios were run locally on 2026-08-10:

- `success`
- `generic_decline`
- `insufficient_funds`

Two redacted response fragments were retained in the review trail and are summarized below. The other two scenarios were executed locally but their raw response bodies are not reproduced in this repository record.

### Insufficient-funds decline

Observed response fields:

```json
{
  "provider": "stripe",
  "environment": "test",
  "scenario": "insufficient_funds",
  "livemode": false,
  "http_result": 402,
  "error_type": "card_error",
  "card_brand": "visa",
  "test_card_last4": "9995",
  "cvc_check": "pass",
  "three_d_secure_supported": true

```

The Stripe test response was returned as an HTTP 402 card error, which the script prints before re-raising the HTTP exception. The traceback is therefore part of the deliberately failed payment path rather than a transport or authentication failure.
